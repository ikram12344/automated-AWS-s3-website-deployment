 AWS S3 Website Deployment

A simple static website deployed to Amazon S3 using GitHub Actions.

 Project Overview

This project demonstrates a basic CI/CD workflow:
1. Edit the website locally.
2. Push changes to GitHub.
3. GitHub Actions deploys the website to an S3 bucket.

 Files

- `index.html` — the website homepage.

 Tools

- HTML
- GitHub
- GitHub Actions
- Amazon S3

Status

The website file is in the repository. AWS deployment setup is the next step.
